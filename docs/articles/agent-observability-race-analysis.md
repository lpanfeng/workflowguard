# Agent 可观测性赛道全景分析

> 日期：2026-06-14 | 分析师：攀峰

---

## 一、赛道定义

**Agent 可观测性（Agent Observability）**：指对 AI Agent 的行为进行实时监控、记录、审计和回溯的技术和产品领域。

**核心问题**：Agent 在执行任务时做了什么？谁授权了它做？结果如何？出了问题怎么追溯？

## 二、赛道参与者分析

### 1. BitBoard（YC P25）

**定位**：Analytics Workspace for Agents
- 为 Agent 提供分析工作台
- 关注 Agent 行为数据的可视化和分析
- YC 背书，融资背景
- 目标用户：构建和运营 Agent 的企业

**优势**：
- YC P25 品牌背书
- 专注于 Agent 行为分析

**劣势**：
- 偏向"分析"而非"治理"
- 缺乏审批和干预能力
- 定位偏高端，中小企业门槛高

### 2. Claw Patrol（Deno 官方）

**定位**：安全防火墙
- 为 AI Agent 提供安全防护
- Deno 官方出品，技术实力强
- 关注 Agent 的"安全边界"
- 更偏向技术层的安全控制

**优势**：
- Deno 官方出品，技术可信度高
- 聚焦安全，专业深度强
- 开发者生态好

**劣势**：
- 定位偏技术层，业务层覆盖不足
- 缺乏审批工作流
- 更适合作为底层安全组件，而非独立产品

### 3. WorkflowGuard（我们）

**定位**：人机协作工作流平台
- Agent 执行 → 人工审批 → 全程审计
- 覆盖执行、审批、审计全链路
- 面向中小企业的轻量级方案

**差异化优势**：
- **审批工作流**：BitBoard 和 Claw Patrol 都没有覆盖的核心功能
- **中小企业定位**：价格低、部署简单、开箱即用
- **全链路覆盖**：从 Agent 执行到人工审批到审计日志
- **飞书集成**：在中国市场有天然优势

**定位地图**：
```
                    高端/复杂          轻量/易用
                      ↑
                      |
   Claw Patrol ───────┼───────────────
   (安全深度)          |              |
                      |              |
                      |   WorkflowGuard
                      |   (审批+审计)
   BitBoard ──────────┼───────────────
   (分析深度)          |              |
                      ↓
              面向大型企业      面向中小企业
```

## 三、市场空白

1. **"审批+审计"的轻量级方案稀缺**
   - 大厂有复杂的 BPM/ERP 系统
   - 初创团队用 Excel 或 Google Sheets
   - 中间市场几乎空白

2. **AI Agent 特有的审批需求未被满足**
   - 传统审批系统不支持"AI 执行→人工审批"模式
   - 需要理解 AI 输出内容再做判断
   - 需要审计 AI 的完整执行过程

3. **中国市场的 AI 治理工具空白**
   - 飞书生态深度整合
   - 中文内容审核
   - 符合中国数据合规要求

## 四、WorkflowGuard 差异化策略

### 核心差异点

| 维度 | BitBoard | Claw Patrol | WorkflowGuard |
|------|----------|-------------|---------------|
| 核心功能 | 行为分析 | 安全防护 | 审批+审计 |
| 目标用户 | 大型企业 | 技术团队 | 中小企业 |
| 价格 | 高端 | 免费/开源 | 低价起步 |
| 部署方式 | SaaS | 本地/云端 | SaaS/私有化 |
| 审批工作流 | ❌ | ❌ | ✅ |
| 飞书集成 | ❌ | ❌ | ✅ |
| 多语言 | 英文 | 英文 | 中英 |

### 战略定位

**WorkflowGuard = Agent 执行治理的"最后一公里"**

- 上游（BitBoard/Claw Patrol）：分析和安全
- 中游（WorkflowGuard）：**审批和审计** ← 我们的核心
- 下游（企业）：合规和追责

**我们不与 BitBoard 和 Claw Patrol 竞争，而是互补。** 一个完整的 Agent 治理方案应该包括：
1. 行为分析（BitBoard）
2. 安全防护（Claw Patrol）
3. **审批审计（WorkflowGuard）** ← 我们填补的空白

## 五、结论

Agent 可观测性赛道正在从"技术讨论"走向"产品落地"。BitBoard 和 Claw Patrol 代表了两个方向：分析和安全。但**审批和审计**是第三个不可替代的方向——因为只有审批才能回答"谁授权了这个操作"这个最核心的问题。

WorkflowGuard 在这个赛道的定位是：**面向中小企业的人机协作审批审计平台**。这个定位避开了与 BitBoard（高端分析）和 Claw Patrol（底层安全）的直接竞争，同时抓住了市场最大的空白——中小企业需要简单、便宜、开箱即用的 Agent 治理方案。
