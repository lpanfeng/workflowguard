## 五、主题拓展

### 1. AI Agent 安全治理

Atlassian Rovo 事件反映了 AI agent 安全治理的三大挑战：

1. **权限管理**：如何确保 agent 只访问必要的数据？
2. **审批机制**：关键操作是否需要人工确认？
3. **审计追踪**：agent 操作是否可追溯？

### 2. WorkflowGuard 的应对策略

WorkflowGuard 通过以下方式应对上述挑战：

1. **审批机制**：每个关键步骤可配置为"AI 执行 + 人工审批"
2. **审计追踪**：所有操作记录在审计日志中
3. **权限隔离**：支持按角色配置访问权限
