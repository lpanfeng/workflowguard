# WorkflowGuard — 人机协作工作流平台

> 想用 AI Agent 但又不敢完全交给 Agent？WorkflowGuard 给你可控的人机协同。

## 一句话定位
面向中小企业的 AI Agent 人机协作工作流平台——Agent 执行、人工审批、全程可审计。

## 核心价值
- **人机协同**：Agent 自动执行 + 关键节点人工审批
- **安全可控**：完整的操作审计日志，一键暂停/回滚
- **开箱即用**：预设工作流模板，5 分钟上手

## 目标用户
- 需要自动化但不敢完全放手的团队管理者
- 中小企业运营/客服/销售团队
- 使用 AI 工具的开发者和内容创作者
